AI-Driven Civic Intelligence & Hyper-Local Air Quality Interventions

Platform Release: v1.0.0

Promptswar Architecture

1. Official Problem Mandate

"Develop an AI-driven civic intelligence solution that enables local authorities, housing societies, and ward-level teams to turn raw air quality data into actionable local interventions. The solution must leverage Generative AI as a core component to interpret pasted or uploaded data tables, including messy ones with inconsistent formats, units, or missing readings, and summarize trends and likely hotspots in plain language. It should recommend prioritized local actions suited to who is asking, since a ward officer, a housing society, and a school can each do different things. Every finding should be traceable to the underlying data, with data gaps and unreliable readings clearly flagged. The assistant should compare each new brief with the previous one to show what changed, and generate both an internal briefing note and a citizen advisory in multiple languages, written for different reading levels, with extra care for children, older adults, and people sensitive to poor air."

2. Architectural Foundations & Deliverables

The CivicAQI platform was systematically architected from ground zero through four comprehensive foundational specifications:

  • PRD.md (Product Requirements Document): Establishes functional requirements FR-1 through FR-10, five distinct civic personas, and measurable KPIs.
  • TRD.md (Technical Requirements Document): Defines the zero-framework runtime topology, native REST endpoints, and security boundaries.
  • DESIGN.md (System Design Document): Details Mermaid data pipelines, responsive vw/vh/rem layouts, and brief-to-brief delta calculation logic.
  • PROMPTS.md (Master Prompt Engineering): Contains few-shot system prompts for multimodal table/vision normalization, 200–300 word executive summaries, and multi-lingual vulnerability stratification.

3. Core Innovation Pillars

Capability Engineering Implementation
Multimodal Ingestion Parses unstructured text, raw CSV/TSV tables, regional language statements, and digital monitor display photos without hallucinating omitted metrics.
Live Ground Truth Cross-Validation Queries live Open-Meteo Air Quality & India Post Pincode APIs, correlated against CPCB/State PCB stations (Rohini, Anand Vihar, RK Puram, BKC, etc.) to detect micro-climate anomalies.
Brief-to-Brief Historical Delta (Δ) Computes Δ AQI = AQI_t - AQI_(t-1), percentage shifts, and categorized trajectory tags (WORSENING, IMPROVING, STABLE) every 30 minutes.
Role-Based Access Control (RBAC) Super Admins & Ward Officers hold direct intervention assignment privileges; RWAs, Schools, and Citizens submit structured requests to designated civic bodies.
Native Canvas Visualizations Pure HTML5 2D Canvas charting pipeline rendering 24-hr smoothed Bezier curves and multi-pollutant safety threshold bars without third-party libraries.

4. Role-Specific Prioritized Intervention Matrix

Persona / Entity P0 Immediate Directives (0–2 Hours) P1 Precautionary Interventions (4–24 Hours)
Ward Officer / Municipal Admin Dispatch mobile high-pressure water misting guns to major traffic arterial points; issue stop-work orders for uncurtained excavation sites. Deploy mechanized vacuum sweepers during off-peak night hours; coordinate traffic diversions to bypass residential zones.
Housing Society / RWA Curtail continuous diesel generator runtime; activate driveway boundary misting sprinklers twice daily. Broadcast WhatsApp smog alerts to residents; enforce strict vehicle no-idling rules at entrance security gates.
School / Educational Authority Immediately suspend all outdoor sports, morning assemblies, and open-air recess; activate classroom HEPA air purifiers. Mandate N95 masks during bus transit; establish an emergency infirmary respiratory triage with nebulizer support.
Commercial & Construction Leads Upgrade HVAC filtration to MERV 13 with indoor air recirculation; cover all sand and cement aggregate piles with tarpaulins. Stagger worker morning arrival shifts away from nocturnal temperature inversion peaks; conduct emission audits on heavy haulers.
Citizens & Vulnerable Households Avoid morning cardio and outdoor exertion; wear certified, fitted N95/FFP2 respirators when stepping outdoors. Submit geo-tagged grievance tickets for open garbage or biomass burning using the platform's Section 133 escalation generator.

6. Technology Stack & ADC Integration Architecture

  • Runtime: Native Node.js HTTP/HTTPS server with zero npm runtime dependencies.
  • UI Framework: Pure Vanilla HTML5 and CSS3 using fluid vw, vh, rem, and clamp() scaling.
  • AI Intelligence & Streaming: Google Vertex AI Gemini models authenticated via Service Account Application Default Credentials (ADC) using native RS256 JWT signing, supporting SSE streaming chat.
  • Authentication: Firebase Authentication REST API with complete local fallback profile persistence in data/users.json.
